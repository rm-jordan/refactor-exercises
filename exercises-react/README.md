# React exercises (optional frontend prep)

For roles that might use **React** in a refactoring round (one component file, not a full app).

| Folder | Focus |
|--------|--------|
| `01-messy-user-card` | Typed props, flatten nested JSX |

Requires `jsdom` (configured in root `vitest.config.ts`).

```bash
npx vitest run exercises-react
npm run reset:react -- 01-messy-user-card
```

Plain TS/JS exercises remain the default prep; use this **just in case**.
